## Arquitetura atual (pipeline)

```
analyze (cortes)
  → mood: 1 frame/cena → montagem S1..SN → Claude Haiku 4.5 → mood global + energia/cena
  → auto-pack: clima dominante → pack (pack_por_clima); "auto" resolve aqui
  → director: plano_de_score (BPM grid + quantize acentos) + composition_plan (arco ElevenLabs)
  → base_bed: cama IA (ElevenLabs arco / Stable Audio fallback)
  → warp: trava o tempo do bed na grade (modo rítmico, best-effort)
  → foley (MMAudio, cortes comuns) + signature (stem, clímax+fim) + bed
  → mix (normalize+fades) → mux → scored.mp4
```

**Dois sinais, duas camadas** (decisão do usuário — [[muntu-sfx-cena-nao-mood]]):

- **mood** (o que a história É) → guia a **trilha** (pack/gênero + arco).
- **cena real** (o que está na tela) → guia o **foley** (MMAudio vê os frames).
- **assinatura** crava clímax + fechamento (brand sting — diferencial anti-commodity).

## Gotchas vencidos (NÃO reintroduzir)

- **Claude vision**: `messages.create` com bloco `image` base64 + `output_config.format`
  (json_schema) → mood+energias garantidos. Haiku 4.5 suporta structured output. Modelo id
  exato = `claude-haiku-4-5` (sem sufixo de data).
- **Montagem** dá o filme inteiro ao VLM em 1 call (1 imagem, ~US$0,0025/vídeo) — ler a
  história é raciocínio, não detecção; Haiku 4.5 ganha de qwen/LLaVA que erram a piada.
- **Warp**: cap 6%; desvio maior = erro de oitava → dobra/divide antes de esticar (não estica
  100%). Só em modo rítmico (livre = BPM arbitrário).
- **Foley MMAudio**: `negative_prompt="music"` (default do modelo) → foley NÃO gera música
  (música é a outra camada). ElevenLabs video-to-sound é **só web, sem API** — por isso MMAudio.
- **ElevenLabs Music V2** é PAGO (free tier 402); `composition_plan` via
  `composition_plan.create(...)` → `compose(composition_plan=...)`; seção usa `lines`, não
  `lyrics`.
