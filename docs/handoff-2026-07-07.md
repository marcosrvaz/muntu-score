## Decisão (o que ficou)

**Camada de sound design = C:**

```
analyze (cortes) → Gemini 2.5 Pro lê a montagem (1 frame/cena) → por cena:
   ambiência (indoor/outdoor + reverb, room tone) + foley (ação com contagem)
 → ElevenLabs text-to-SFX (one-shot por descrição)
 → ambiência cobre o span da cena ; foley colado no tempo do corte (sync = nosso, frame-tight)
```

- **Reader = Gemini 2.5 Pro** via OpenRouter (mais preciso que GLM — pegou o gag "mão presa
  na lata" + contagens tipo "4 footsteps", "3 keyboard clicks"). **SEM `response_format`**
  (Gemini via OpenRouter zera o content com ele) + **`max_tokens` 8000** (raciocínio come tokens
  → senão `finish=length`, content vazio).
- **Sync = nosso** (colocação no tempo do corte), não do gerador — igual aos stems.

## Abordagens testadas + veredito

| Var                    | O quê                                    | Veredito                                    |
| ---------------------- | ---------------------------------------- | ------------------------------------------- |
| MMAudio cego (inicial) | video→áudio, prompt vazio                | ruim: vozes, fora de contexto, fora de sync |
| A                      | HunyuanVideo-Foley whole, cego           | **mete música** (não exclui)                |
| B                      | Hunyuan whole + prompt Gemini            | melhor ambiente, mas **mete música**        |
| D1                     | Hunyuan por cena, cego                   | música + buracos 429                        |
| D2                     | Hunyuan por cena + time-aware            | música + buracos 429                        |
| Híbrido                | ElevenLabs ambiência + MMAudio foley     | funcionou, mas usuário **preferiu C**       |
| **C**                  | **Gemini → ElevenLabs text-SFX → timed** | **GANHOU — limpo, controlável, sem música** |

**Achado central (bate com deep-research verificada, 106 agentes):** os modelos video→áudio
(MMAudio, ThinkSound, **Hunyuan = novo SOTA**) **não expõem negative-prompt** pra excluir
voz/música → contaminam com música. No pipeline em camadas (música = layer separado) isso
desqualifica video→áudio. O C controla o conteúdo (text-SFX) → única opção limpa.
Ressalva: **ElevenLabs video-to-sound é só web** (a API deles é text-to-SFX). Detalhe em
`~/Documentos/career/pesquisa/sound-design-ia-2026-06.md`.
